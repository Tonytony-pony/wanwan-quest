# 🐶 わんわんクエスト

**さんすうで いぬを そだてよう** — たしざんを学びながら犬を育てる、レトロRPG風の Web アプリです。

`index.html` 1ファイルで完結（ビルド不要・サーバー不要）。スマホ／タブレットのブラウザでそのまま遊べます。

---

## あそびかた

1. **きみの なまえ**を入れて「いぬを えらぶ」
1. **ワンワンハウス**（トップメニュー）から一緒に遊ぶ犬をえらび、なまえをつける
2. おさんぽコースをえらぶ
3. たしざんの３つの選択肢から正解をえらぶ
   - **せいかい** → ♥ が **1こ ふえる**
   - **まちがい** → ♥ が **3こ われる**
4. 10問おわると、**のこった ♥ の数だけ なつき度が増える**
5. なつき度が 70 になると **レベルアップ**（犬の見た目が変化）
6. まちがえた問題があれば、結果画面から**おさらい**にちょうせんできる

### 2つのメーターの関係

**なつき度 ＝ いままでのおさんぽで あつめた ♥ の合計**です。
おさんぽ中は ♥ だけが動き、終わったときに ♥ がそのまま なつき度に加わります。

```
 おさんぽ中 : ♥♥♥ から スタート → 正解 +1こ / まちがい −3こ
      ↓  おさんぽ おわり
 のこった ♥ が そのまま なつき度に加算
      ↓
 なつき度 70 で レベルアップ（あまりは次回にもちこし）
```

| おさんぽの結果 | のこる ♥ | もらえるなつき度 |
|---|---|---|
| 全問正解 | 13こ | **+13** |
| 1ミス | 9こ | +9 |
| 2ミス | 5こ | +5 |
| 3ミス | 1こ | +1 |

### おと

- **こうかおん**（♪ボタン）と **BGM**（♬ボタン）を別々に切り替えられます
- 音声ファイルは使わず、Web Audio API のオシレーターでその場で演奏しています。
  BGM はハ長調8小節のループ（`BGM_MELODY` / `BGM_BASS`）。
  ダウンロードが増えず、オフラインでも鳴ります
- ブラウザの制限で、最初のタップまで音は鳴りません（タイトルの開始ボタンで鳴り始めます）
- タブを閉じている間は BGM を止めます

### ごほうび アイテム

犬ごとに、レベルが届くともらえます。おさんぽ画面に少しずつ物が増えていきます。

| レベル | アイテム | 効果 |
|---|---|---|
| 10 | いぬ小屋 | おさんぽ開始の ♥ が 3こ → 4こ |
| 15 | ごはんの おさら | おさんぽ中1回だけ、まちがえても ♥ が割れない |
| 20 | ボール | 3問れんぞく正解ごとに ♥ ＋1 |
| 25 | きんの メダル | おさんぽ終了時に なつき度 ＋5 |

小屋は犬の左うしろ、ボールとごはんは右手前、メダルは名前の横のバッジとして
表示されます。ワンワンハウスのカードにも、持っているアイテムが小さく並びます。

所持は**レベルから導出**しているのでセーブには保存していません
（`ITEMS` / `hasItem()` を参照）。4つそろうと全問正解の日が
♥13 → ♥17＋メダル5 ＝ なつき度22 になり、約1.7倍のペースになります。

画像は `img/house.png` `bowl.png` `ball.png` `medal.png`。
元画像は `イラスト犬/items/` に置き、次のコマンドで変換します。

```bash
python tools_make_dog_png.py items
```

### レベルアップのペース

**1日1コース（10問）＝ 週1回レベルアップ**になるよう `AFFECTION_MAX = 70` にしています。

| 毎日のできぐあい | 1日にたまる ♥ | レベルアップまで |
|---|---|---|
| 全問正解 | 13こ | **6日** |
| 1ミス | 9こ | **8日** |
| 2ミス | 5こ | 14日 |

1日に2コース遊べばこの半分の日数になります。

**♥ が 3こ より少ないときに間違えると、いぬが いなくなります**（その日の ♥ はゼロ）。
なつき度（これまでの貯金）は減りません。
画面には「あぶない！ つぎ まちがえると いぬが いって しまう」と警告が出ます。

間違えた**場所**では結果が変わりません（1問目でミスしても10問目でミスしても ♥9こ）。

### おさらい（まちがえた問題の再ちょうせん）

10問終わった結果画面に、**「まちがえた ◯もんに もう一かい こたえる」**という
金色のボタンが出ます（まちがいが0問のときは出ません）。

- **せいかい** → ♥ が 1こ ふえる（＝なつき度も +1）／にがて度が 1つ へる
- **まちがい** → **なにも へらない**。答えを見せて次へ進むだけ

失うものがないので、こわがらずに何度でも挑戦できます。
同じ式を2回まちがえても、おさらいには1回だけ出ます。
おさらいは1回の結果画面につき1度きりです。

### コース（難易度）

| コース | 内容 | 解放条件 |
|---|---|---|
| 🌷 はじまりの にわ | 1けた＋1けた（くりあがりなし） | 最初から |
| 🌳 ぼうけんの こうえん | 1けた＋1けた（くりあがりあり） | 前のコースをクリア |
| 🍄 むずかしの もり | 2けた＋1けた | 前のコースをクリア |
| ⛰ でんせつの やま | 2けた＋2けた | 前のコースをクリア |

1コース = 10問。♥ を切らさずに10問終えるとクリア＝次のコースが解放されます。

### 犬のせいちょう

| レベル | すがた |
|---|---|
| 1〜2 | こいぬ |
| 3〜4 | わんこ |
| 5〜7 | たくましい 犬 |
| 8〜 | でんせつの 犬（かんむり＋マント） |

### にがて問題の記録

まちがえた問題（`5 + 6` など）は回数を記録し、次から
**「⚠ ちゅういして こたえよう！」** のメモ付きで、優先的に出題されます（約40%）。
おさんぽ画面の「にがてな もんだい」に上位5件が一覧表示されます。

**おさらいで正解すると、にがて度が1つ減ります**（0になるとリストから消えます）。
苦手を登録するだけでなく、卒業もできる仕組みです。

## データの保存

`localStorage`（キー: `wanwanquest_save_v1`）に以下を保存します。

**犬ごと**（`dogs.<犬種>`）: なまえ / レベル / なつき度
**全体で共有**: きみのなまえ / 今えらんでいる犬 / コース解放状況 /
にがて問題の記録 / 音のON・OFF

犬は何匹でも育てられ、レベルは犬ごとに貯まります。コースの解放とにがて問題は
子どもの学習の進み具合なので、どの犬で遊んでも共通です。
（古い1匹だけのセーブは、起動時に自動でビーグルへ引き継がれます）

リロードしても続きから遊べます。
※ localStorage が使えない環境（プライベートブラウズ等）でも、保存されないだけでゲームは動きます。

やり直したいときは、おさんぽ画面の「さいしょから やりなおす」ボタンから。

## GitHub Pages で公開する

### A. ブラウザだけで公開（かんたん）

1. GitHub にログイン → 右上の **＋** → **New repository**
2. Repository name に `wanwan-quest`、**Public** を選んで **Create repository**
3. 作られたページの **uploading an existing file** をクリックし、`index.html` をドラッグ＆ドロップ →
   **Commit changes**
4. リポジトリの **Settings** → 左メニュー **Pages**
5. *Build and deployment* の Source を **Deploy from a branch**、
   Branch を **main** / **/(root)** にして **Save**
6. 1〜2分待つと、Pages のページに公開 URL が出ます

```
https://<あなたのユーザー名>.github.io/wanwan-quest/
```

この URL をスマホ・タブレットで開けば遊べます。

### B. コマンドで公開

このフォルダは git リポジトリとして初期化＆コミット済みです。
`<あなたのユーザー名>` を書きかえて実行してください。

```bash
git remote add origin https://github.com/<あなたのユーザー名>/wanwan-quest.git
git branch -M main
git push -u origin main
```

そのあと **Settings → Pages** で上記 5. と同じ設定をします。

### スマホのホーム画面に置く

公開 URL を開いて…

- **iPhone / iPad (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: 右上の︙ → 「ホーム画面に追加」

アプリのように全画面で遊べます。

## ローカルで動かす

`index.html` をダブルクリックするだけでも動きます。
ただし `file://` では保存（localStorage）が効かないブラウザがあるので、
その場合はこのフォルダで簡易サーバーを立ててください。

```bash
python -m http.server 8777
```

→ ブラウザで `http://localhost:8777/` を開く

## 技術メモ

- HTML / CSS / JavaScript のみ。フレームワーク・ビルドツールなし
- 外部読み込みは Google Fonts（`DotGothic16`）**1件のみ**。
  オフラインでも `MS Gothic` 等にフォールバックして動作します
- 犬のイラストは `img/*.png`（Gemini で生成）。差し替えは `DOG_IMG` の対応表だけ

| ファイル | 使う場面 |
|---|---|
| `img/<犬種>_lv1.png` | レベル1〜2 |
| `img/<犬種>_lv3.png` | レベル3〜4 |
| `img/<犬種>_lv5.png` | レベル5〜 |
| `img/<犬種>_sad.png` | 不正解（そっぽを向く） |
| `img/paw.png` | いぬがいなくなった（全犬種で共有） |

  - 元画像は `イラスト犬/<犬種>/01〜04` と `イラスト犬/paw`（.jpg/.png/.webp可）。
    次のコマンドでアプリ用のサイズに変換します。

  - **保存は透過PNGを強く推奨します。** 透過PNGならそのまま使うので一番きれいです。
    JPGで保存すると透過が「市松模様」として画像に焼き込まれてしまい、
    スクリプトが格子を検出して除去しますが、犬の輪郭に接したマスが
    わずかに残ることがあります。

```bash
python tools_make_dog_png.py
```

  - 512×512キャンバスに配置し、**足元の高さを統一**（レベルアップで絵が飛ばない）。
    犬は下端そろえ、あしあとは中央そろえ
  - 1犬種だけ作り直したいときは `python tools_make_dog_png.py shiba` のように
    フォルダ名を渡します（あしあては `paw`）
  - 犬種の一覧と公開状態は `index.html` の `BREEDS`。画像を用意したら
    その犬種の `ready` を `true` にすると「ワンワンハウス」で選べるようになります

| 犬種 | フォルダ |
|---|---|
| ビーグル | `beagle` |
| しばいぬ | `shiba` |
| ミニチュアダックス | `dachshund` |
| ポメラニアン | `pomeranian` |
| チワワ | `chihuahua` |
| フレンチブルドッグ | `frenchbulldog` |
| ビションフリーゼ | `bichon` |
| ゴールデンレトリバー | `golden` |
| ハスキー | `husky` |

  - **Gemini に描かせるときは背景を単色グリーン（#00FF00）にしてください。**
    Gemini は本当の透過を出力できず、`transparent background` と指示すると
    「透過を表す市松模様」を絵として描いてしまいます。
    グリーンバックならスクリプトが四隅の色から自動判定してきれいに抜きます
  - 離れた図形（あしあとの肉球など）も残るよう、最大の塊の2%以上を採用します
  - `tools_draw_dog.py` は以前使っていた76×76ドット絵の生成スクリプト。
    本体からドット絵の描画コードは削除済みですが、参考として残してあります
- 効果音は Web Audio API のオシレーターで生成（音声ファイルなし）
- モバイルファースト（`max-width: 480px` 中央配置）

### バランス調整したいとき

`index.html` の「0. せってい」ブロックの定数を変更してください。

```js
var QUESTIONS_PER_RUN = 10;   // 1コースの問題数
var AFFECTION_MAX     = 70;   // レベルアップに必要な ♥ の数（= 約1週間）
var HEART_START       = 3;    // おさんぽ開始時にもっていく ♥ の数
var HEART_UP          = 1;    // 正解1回でふえる ♥
var HEART_DOWN        = 3;    // 不正解1回でわれる ♥
var WEAK_RATE         = 0.4;  // にがて問題が出る確率
```

- **レベルアップの間隔を変えたい** → `AFFECTION_MAX`。だいたい `1日にたまる♥ × 日数` で決まります
  （2週間に1回なら 140、3日に1回なら 30）
- **やさしくしたい** → `HEART_START` を 5 に（最初のミスに余裕ができる）
- **きびしくしたい** → `HEART_DOWN` を 4 に（2ミス目で終わりやすくなる）
- **1日にたくさん遊ばせたい** → `QUESTIONS_PER_RUN` を 20 に（1コースあたりの ♥ も増えます）
